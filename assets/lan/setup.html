Secure mode setup

One-time setup so the VR player can use head tracking (iOS only allows motion sensors on secure pages). Takes about a minute.

  1. Download this PC's certificate:
    Download certificate
    Safari asks to download a configuration profile: tap Allow, then Close.
  2. Install it: Settings → General → VPN & Device Management → PML Local CA → Install.
  3. Trust it: Settings → General → About → Certificate Trust Settings → switch on PML Local CA.
  4. Open the secure page:
    Open secure library
    Then Share → Add to Home Screen for fullscreen. Use that icon from now on (you can delete the old one).

The certificate only works for this PC's library. If the page says it's not secure, check step 3. If it doesn't load at all, port must be allowed in the PC's firewall.
